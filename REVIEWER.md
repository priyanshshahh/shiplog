# Reviewer guide — shiplog

Peer review target for Hult Cohort Summer Pilot 2026 · Project 3 (vibe marketing).

**Production:** https://shiplog-snowy.vercel.app  
**Repo:** https://github.com/priyanshshahh/shiplog  

## Pass checklist (from curriculum)

- [ ] Public homepage loads over HTTPS with cohort narrative  
- [ ] Student profiles with name / GitHub / bio / photo  
- [ ] Portfolio links to live deploys (+ repos where present)  
- [ ] PM status visible (`/status` or home PM panel)  
- [ ] `/partners` + request intro form  
- [ ] Privacy opt-out respected  
- [ ] SEO metadata present  
- [ ] Mobile readable  

## Suggested walkthrough

1. Home → open a featured ship card → deploy + profile  
2. `/cohort` → filter / search → open `@priyanshshahh`  
3. Sign in with GitHub → `/me` → confirm edit UI exists  
4. `/partners` → skim intro form fields  
5. File review issue on this repo; optional `Vote: up`  

## Do not expect

- On-site vote tallies (program forbids; ballot is GitHub)  
- SMTP delivery for intro/RSVP (logged + addressed to placement)  

## Rubric hints

| Dimension | Where to look |

| Core functionality | Profiles, partners, PM, privacy, SEO |
